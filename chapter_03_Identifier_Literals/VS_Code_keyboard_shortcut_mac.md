# VS Code Keyboard Shortcuts – Mac (Default)

**Key symbols:** `⌘` Cmd · `⌥` Option · `⇧` Shift · `⌃` Control

## General

| Shortcut | Action |
|---|---|
| `⇧ ⌘ P` / `F1` | Command Palette |
| `⌘ P` | Quick Open / Go to file |
| `⇧ ⌘ N` | New window |
| `⇧ ⌘ W` | Close window |
| `⌘ ,` | Settings |
| `⌘ K` `⌘ S` | Keyboard shortcuts list |

## Basic Editing

| Shortcut | Action |
|---|---|
| `⌘ X` | Cut line (no selection) |
| `⌘ C` | Copy line (no selection) |
| `⌥ ↑` / `⌥ ↓` | Move line up / down |
| `⇧ ⌥ ↑` / `⇧ ⌥ ↓` | Copy line up / down |
| `⇧ ⌘ K` | Delete line |
| `⌘ Enter` | Insert line below |
| `⇧ ⌘ Enter` | Insert line above |
| `⇧ ⌘ \` | Jump to matching bracket |
| `⌘ ]` / `⌘ [` | Indent / Outdent line |
| `⌘ ←` / `⌘ →` | Go to start / end of line |
| `⌘ ↑` / `⌘ ↓` | Go to start / end of file |
| `⌘ /` | Toggle line comment |
| `⇧ ⌥ A` | Toggle block comment |
| `⌘ K` `⌘ C` | Add line comment |
| `⌘ K` `⌘ U` | Remove line comment |
| `⌥ ⌘ [` / `⌥ ⌘ ]` | Fold / Unfold region |
| `⌘ K` `⌘ 0` | Fold all |
| `⌘ K` `⌘ J` | Unfold all |
| `⌥ Z` | Toggle word wrap |
| `⌘ Z` | Undo |
| `⇧ ⌘ Z` | Redo |
| `⌘ S` | Save |
| `⇧ ⌘ S` | Save as |
| `⌥ ⌘ S` | Save all |

## Multi-Cursor and Selection

| Shortcut | Action |
|---|---|
| `⌥ Click` | Add cursor |
| `⌥ ⌘ ↑` / `⌥ ⌘ ↓` | Add cursor above / below |
| `⌘ U` | Undo last cursor operation |
| `⇧ ⌥ I` | Add cursor at end of each selected line |
| `⌘ L` | Select current line |
| `⌘ D` | Select next occurrence of word |
| `⇧ ⌘ L` | Select all occurrences of selection |
| `⌘ F2` | Select all occurrences of current word |
| `⌃ ⇧ ⌘ →` / `⌃ ⇧ ⌘ ←` | Expand / Shrink selection |
| `⇧ ⌥ Drag` | Column (box) selection |

## Search and Replace

| Shortcut | Action |
|---|---|
| `⌘ F` | Find |
| `⌥ ⌘ F` | Replace |
| `⌘ G` / `⇧ ⌘ G` | Find next / previous |
| `⌥ Enter` | Select all matches of Find |
| `⇧ ⌘ F` | Search in all files |
| `⇧ ⌘ H` | Replace in all files |
